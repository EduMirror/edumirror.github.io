# API 设置

“我的 API 设置”用于配置平台调用的文本模型、图片生成和视频生成服务。API 配置会影响模拟分析、Rater 评估、提示词生成以及漫画和视频等媒体内容的生成。

如果平台已经提供可用的默认配置，普通用户通常不需要修改 API 设置。只有在平台管理员或服务提供方要求使用自己的模型服务时，才需要进入此页面进行配置。

## 配置类型

API 设置页面分为三个标签：

| 配置类型 | 主要用途 |
| --- | --- |
| 文本模型 | 用于角色对话与决策、场景分析、Rater 评估和提示词生成。 |
| 图片生成 | 用于根据模拟结果生成场景漫画或其他图片内容。 |
| 视频生成 | 用于根据模拟结果生成演示视频。 |

切换标签后，可以分别为不同类型的服务填写对应配置。

## 文本模型配置

文本模型配置通常包含以下字段：

- **供应商**：选择 API 服务商；
- **API Key**：如果使用平台提供的默认模拟服务，可以留空；只有需要使用自己的模型服务时，才填写服务商提供的密钥；
- **Base URL**：填写服务商提供的 API 地址，例如兼容 OpenAI 接口的服务地址；
- **模型名称**：填写要调用的具体模型名称。

模型名称必须与服务商实际提供的模型保持一致。Base URL 或模型名称填写错误时，测试连接和后续模拟都可能失败。

## 图片和视频生成配置

切换到“图片生成”或“视频生成”标签后，可以分别配置对应的生成服务。通常需要填写供应商、API Key、Base URL 和模型或服务名称，具体字段以当前页面显示为准。

图片生成配置主要用于场景漫画等视觉内容；视频生成配置主要用于将模拟过程整理为演示视频。配置完成后，还需要在模拟结果页面提交对应的生成任务。

## 测试和保存

填写或修改配置后，建议按照以下顺序操作：

1. 点击“测试连接”，确认平台能够访问服务商并识别模型；
2. 测试成功后点击“保存”，使配置正式生效；
3. 返回模拟或媒体生成页面，确认相关功能能够正常使用。

如果不再使用某个配置，可以点击“删除配置”，然后重新选择其他可用配置。

## 常见问题

### 测试连接失败

优先检查以下内容：

- API Key 是否有效、是否已经过期；
- Base URL 是否完整且填写正确；
- 模型名称是否与服务商提供的名称一致；
- 服务商账号是否还有可用额度；
- 当前网络是否能够访问该服务。

### 平台默认服务和使用限制

EduMirror 会为每个用户提供可以直接使用的默认模拟服务。使用默认服务时，不需要自行申请或填写 API Key，登录后即可运行平台支持的模拟功能。

默认服务可能受到每日使用次数、并发数量或平台资源的限制。页面通常会显示当前账号的剩余运行次数；如果达到当日上限，平台会在运行前给出提示。具体可用次数和限制以平台当前页面显示为准。

如果你需要使用自己的模型服务，可以填写 API Key、Base URL 和模型名称，保存后使用个人配置。个人配置是否可用，还取决于对应服务商的账号权限、调用额度和网络状况。
