# 账号与反馈

## 注册

在登录页面点击“申请注册”，填写页面要求的信息并提交申请。申请审核通过后，按照邮件中的激活链接完成账号激活和密码设置。

如果没有收到邮件，请先检查垃圾邮件或联系平台管理员。

## 登录与退出

登录后，页面右上角会显示当前账号。点击账号区域的“更多操作”，可以找到退出登录等操作。

## 运行次数

账号区域会显示当天剩余的模拟运行次数。运行次数不足时，平台会在开始运行前提示，避免重复提交。

## 联系作者与提交反馈

点击页面顶部的“联系作者”可以提交反馈。反馈类型包括：

- 报告 Bug；
- 联系作者；
- 寻求合作；
- 产品建议；
- 账号问题；
- 其他。

请尽量描述出现问题的页面、操作步骤和看到的提示。如果需要说明界面问题，可以附上截图。

不要在反馈中填写密码、API 密钥或其他敏感信息。
