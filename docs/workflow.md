# 完整操作示例

下面按照实际操作顺序，完成一次模拟。

## 第一步：选择场景

在“选择实验场景”页面点击一个场景卡片。

```{image} _static/screenshots/01-select-scenario.png
:alt: 选择实验场景页面截图
:width: 100%
:align: center
```

如果场景较多，可以在搜索框输入关键词，也可以使用底部的翻页按钮。

## 第二步：检查并编辑场景

进入“编辑场景”后，左侧会列出基准条件和干预条件。点击某个场景，右侧会显示互动要求和角色已知信息。

```{image} _static/screenshots/02-edit-scenario.png
:alt: 编辑场景页面截图
:width: 100%
:align: center
```

确认内容后点击“保存修改”，再点击“确认并继续”。如果不需要修改，也建议先阅读场景要求。

## 第三步：检查角色

在“配置角色”页面，先确认顶部显示的运行范围，再按“条件 → 子场景 → 角色卡片”的顺序检查参与者。

```{image} _static/screenshots/03-configure-roles.png
:alt: 配置角色页面截图
:width: 100%
:align: center
```

角色卡片会显示姓名、角色类型、目标和行为特征。同一角色可能出现在多个子场景中，编辑一次会更新整个实验场景中的共用设定。需要调整时，点击对应角色的“编辑”，保存后回到列表确认内容，再点击“确认并继续”。

## 第四步：选择运行范围

进入“运行模拟”后，选择“基准条件”“干预条件”或“全部实验条件”。第一次建议选择“基准条件”。

```{image} _static/screenshots/04-run-simulation.png
:alt: 运行模拟页面截图
:width: 100%
:align: center
```

选择运行范围后点击“开始运行”。运行期间页面会显示实时日志，完成后点击“查看结果”。

## 第五步：查看结果

结果页面会先展示整体过程总结和角色状态分析，再提供心理测量与行为分析结果。

```{image} _static/screenshots/05-results-analysis.png
:alt: 结果分析页面截图
:width: 100%
:align: center
```

先看完整过程，再看各类分析结果，最后比较基准和干预条件。

## 第六步：回看历史记录

在结果页面点击“媒体生成”可以进入漫画和视频生成页面。

```{image} _static/screenshots/06-media-generation.png
:alt: 媒体生成页面截图
:width: 100%
:align: center
```

下一次登录后，也可以从左侧“历史模拟”中打开过去的记录，重新查看结果、日志和媒体生成入口。
