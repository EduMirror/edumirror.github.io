# 结果与测量

## 1. 结果页入门

### 1.1 先看什么

确认模拟已完成，并确认当前查看的是哪一个实验条件。结果页不是一个单独的分数，而是把整体过程、角色状态、Surveyor、Rater 和原始互动日志放在一起回答不同问题：

1. 先看整体过程总结，了解主要事件和转折；
2. 再看角色状态，确认需求缺口、状态指标和行动时间线如何变化；
3. 在对应条件下查看 Surveyor 的量表汇总和逐题回答；
4. 查看 Rater 的行为命中、评分和证据；
5. 对有疑问的读数点击“查看日志”，核对实际发生的步骤、对话和事件；
6. 用相同的顺序查看其他条件，再做比较。

这里的 Surveyor 问卷由模拟中的 AI 角色作答，用来记录模拟角色在量表题目上的回答；它不是真实人群调查，也不代表真实受试者样本。

### 1.2 区域、条件和总体总结

结果页的整体过程总结通常包括全局步骤数、事件数、场景数，以及从开始到结束的主要互动、变化和转折。下面的示例中，当前基准条件显示 16 个状态步、16 条日志和 3 个场景；这些数字描述当前条件保存的模拟过程，不是 Surveyor 或 Rater 的测量分数。

```{image} _static/screenshots/05-results-analysis.png
:width: 100%
:align: center
```

“条件”按钮用于整体过程总结和角色状态视图的切换。Surveyor 和 Rater 不依靠这个按钮切换，而是在各自区域内按条件分组显示；阅读它们时，应进入对应的条件组。基准条件表示没有加入额外干预的流程，干预条件表示加入某项干预后的流程。只有同时有可比较的条件时，才适合讨论干预前后的差异。

总结用于快速了解全局，不代替逐步日志。发现总结与预期不一致时，点击“查看日志”，核对角色实际做了什么、干预何时发生，以及哪些角色实际接触到干预。

## 2. 角色状态

角色状态分析来自模拟过程中持续记录的角色状态，不是问卷结果，也不是 Rater 评分。先选择条件，再选择角色和状态视图；可查看需求缺口、社会价值取向（SVO）、自身满意度和他人满意度。

### 2.1 选择条件、角色和状态视图

角色状态区域可以按条件和角色切换。当前卡片显示角色目标、状态特征、关键变化和状态指标；状态步数、行动数等标签帮助确认当前数据覆盖到哪一步。

```{image} _static/screenshots/09a-results-role-summary.png
:width: 100%
```

### 2.2 读曲线和核心需求

状态曲线的横轴是全局步骤，悬停在曲线上可查看某一步的数值和对应行动。曲线解释应回到行动时间线和完整日志，核对对应事件，而不是把曲线变化单独当作原因。

```{image} _static/screenshots/09b-results-role-detail.png
:alt: 角色状态明细，显示 SVO 曲线和核心需求明细
:width: 100%
:align: center
```

核心需求以 0—10 的数值记录：

| 字段 | 含义 |
| --- | --- |
| 初始值 | 模拟开始时该需求的状态 |
| 最终值 | 当前条件结束时该需求的状态 |
| 期望值 | 该角色希望达到的状态 |
| 需求缺口 | 期望值减去当前值 |
| 变化 | 最终缺口减去初始缺口 |

需求缺口大于 0 表示当前值低于期望值，等于 0 表示达到期望值，小于 0 表示超过期望值。“变化”为负表示缺口缩小，为正表示缺口扩大。总需求缺口是各项需求缺口的合计；需要定位具体变化时，应查看核心需求明细。

“最大缺口”表示最终状态下与期望值差距最大的核心需求；“变化最大”表示从初始状态到最终状态，缺口变化幅度最大的核心需求。自身满意度和他人满意度是模拟中的连续状态指标，不是角色填写的满意度问卷；SVO 的变化也是本次模拟中的状态记录。

## 3. Surveyor：模拟 AI 角色的问卷回答

Surveyor 使用场景配置的问卷或心理量表，让指定的模拟 AI 角色逐题作答，并按当前量表实现生成汇总结果。每个场景可配置不同量表和被调研对象，具体工具应以页面当前列出的配置为准。

### 3.1 先看量表和聚合结果

先确认量表名称、量表说明、受测者和当前条件，再读结果概览中的受测者数、题目数、汇总指标和测量对象。分数高低必须结合量表说明解释，不能把不同量表的原始数值直接比较。

### 3.2 展开逐条记录核对汇总

展开“逐条记录”可以查看受测者聚合明细，例如各维度或各分量的总和、均值。它与逐题问答不是两次调查：前者是受测者层面的聚合指标，后者是逐题明细。

```{image} _static/screenshots/10d-results-surveyor-expanded-record.png
:alt: Surveyor 展开逐条记录后的聚合结果，显示量表概览和受测者测量记录
:width: 100%
:align: center
```

Surveyor 记录的数据来源是模拟 AI 角色对量表题目的作答，不要求互动日志中出现同名行为。解读时仍应结合互动日志，确认问卷结果对应的模拟经历。

### 3.3 查看逐题问答和编码

如果页面提供“调研员问答”，展开后核对每一道题的题目、回答、保存量值和维度归属。常见字段如下：

| 字段 | 含义 |
| --- | --- |
| Agent | 当前问答对应的模拟角色 |
| ID | 题目标识，用于核对同一道题 |
| Statement | 量表题目或陈述文本 |
| Answer | 模拟 AI 角色对该题保存的文字回答 |
| Value | 按当前量表实现编码后保存的答案量值 |
| Dimension | 该题所属的量表维度（如果当前量表提供） |

```{image} _static/screenshots/10e-results-surveyor-questionnaire-answers.png
:alt: ERQ 逐题问答示意（根据界面示例整理），显示题目、受测者回答、量值和维度
:width: 100%
:align: center
```

Value 是答案对应的数值编码。例如，当前 ERQ 的七个选项保存为 0—6，图中的“同意”对应 5。查看时要同时核对 Answer 和量表说明；不同量表的编码和汇总规则可能不同。比较条件时，先确认量表、受测者和题目一致，再比较相应汇总指标。

## 4. Rater：基于日志的行为分析

Rater 根据当前条件的互动日志和场景评分标准，分析日志中是否出现符合标准的外显行为。它与 Surveyor 的问卷回答互相补充：Surveyor 记录模拟 AI 角色如何回答量表，Rater 记录互动日志中是否有评分标准支持的行为证据。

### 4.1 运行和查看评分

1. 展开“大模型评分员（行为分析）”；
2. 在“评分对象”中选择需要分析的角色；
3. 从当前场景的评分维度中选择一项或多项；
4. 点击“运行评分”；
5. 在对应实验条件下查看生成的评分卡片。

```{image} _static/screenshots/11a-results-rater-baseline.png
:alt: Rater 行为分析区域，显示评分对象、评分标准和运行评分操作
:width: 100%
:align: center
```

评分过程读取当前条件的完整事件日志，按评分标准检查行为，并保留有对话或事件证据支持的记录。部分结果会随模拟一起生成；更换评分对象或评分维度后，可以在结果页重新运行评分。

### 4.2 读评分卡片和证据

评分卡片显示的字段随评分工具和已有记录而变化，常见字段如下：

| 字段 | 阅读方式 |
| --- | --- |
| 检出行为数 | 当前评分标准下有证据支持的命中记录数量 |
| 平均分 | 命中记录在当前评分标准下的平均值（若提供） |
| 平均严重程度 | 命中行为的平均严重程度（若提供） |
| 主要角色 | 命中记录中出现较多的角色（若提供） |
| 代表性证据 | 从日志提取的摘要证据（若提供） |
| 逐条测量记录 | 与命中行为对应的步骤、场景、角色、类别、分数或证据（按结果提供） |

“没有检出行为”表示当前日志中没有找到符合该评分标准的明确证据，不等于证明行为绝对不存在。命中数、分数和严重程度只能在相同评分标准下比较；最终判断应展开可用的逐条记录，并回看完整日志。

## 5. 条件比较

### 5.1 按同一顺序比较

比较基准条件和干预条件时，保持角色、状态指标、量表、受测者和评分标准一致：

| 层级 | 先看什么 | 再用什么确认 |
| --- | --- | --- |
| 互动过程 | 主要事件和转折是否不同 | 查看日志，确认干预何时发生、角色如何回应 |
| 角色状态 | 需求缺口、满意度和 SVO 如何变化 | 查看变化所在的全局步骤和对应行动 |
| Surveyor | 同一量表、同一受测者的聚合结果是否变化 | 核对逐题 Answer、Value 和量表编码 |
| Rater | 命中记录和可见汇总字段是否变化 | 展开逐条证据并回看完整日志 |

日志用于解释比较结果：核对干预何时发生、哪些角色实际接触到干预、角色随后采取了什么行动，以及这些行动是否对应状态或测量结果的变化。日志、状态、Surveyor 和 Rater 的数据来源不同，不能用其中一类结果替代其他类别的证据。

例如，同一角色的某项需求在基准条件最终缺口为 4、干预条件为 1，只能说明这次模拟中干预条件下距离期望状态更近。还应检查相同量表的 Surveyor 记录、可用的 Rater 记录和完整日志；一次运行中的差异不能单独证明普遍因果效果。

不同量表的范围、方向和编码可能不同，不能直接比较不同量表的原始数值。测量结果还应保留实验条件、角色设定、可用的测量记录和原始互动日志。

## 6. 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 没有 Surveyor 或 Rater 结果 | 先确认模拟是否完成，再查看测量工具箱、当前条件分组和页面提示；当前场景也可能没有配置对应工具。 |
| 只有基准条件 | 需要运行干预条件或选择全部实验条件，才可以进行前后比较。 |
| 有问卷量值但没有对应行为证据 | 这是可能的：Surveyor 来自模拟 AI 角色的问卷作答，不要求日志中出现同名行为；Rater 才依据互动日志和评分标准进行行为分析。 |
| “真实模型”和“模拟测试”标签 | 标签表示测量结果使用的运行模式。应确认结果卡片显示的模式符合当前用途，测试模式结果不应直接当作正式结论。 |
| 旧结果缺少图表、总结或字段 | 先查看已有日志和测量记录；如果需要完整的新结果结构，应重新运行场景。 |
