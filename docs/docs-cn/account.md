# 账号与反馈

## 注册

在登录页面点击“申请注册”，可选择邮箱注册或手机号注册。邮箱注册需经过申请审核与邮件激活；注册时填写的手机号暂不能用于登录，登录后可在“账号设置”中通过短信验证激活手机号登录。手机号注册需填写密码、基本信息和申请用途，邮箱可不填；短信验证码通过后即可登录，无需审核。

如果没有收到邮件，请先检查垃圾邮件或联系平台管理员。

## 登录与退出

使用注册邮箱或已验证的手机号，加上同一个密码登录。忘记密码时，可通过已设置的邮箱接收重置链接，或使用已验证手机号接收短信验证码。手机号注册时填写的可选联系邮箱也可用于登录。

登录后，页面右上角会显示当前账号。点击“更多操作”→“账号设置”，可以修改密码、通过短信验证码激活注册时填写的手机号或新增、更换手机号，以及通过新邮箱验证码新增或更换登录邮箱。手机号验证通过后即可用它和现有密码登录；修改密码后需重新登录。智思体账号的登录凭据由智思体管理。

## 运行次数

账号区域会显示当天剩余的模拟运行次数。运行次数不足时，平台会在开始运行前提示，避免重复提交。

## 联系作者与提交反馈

点击页面顶部的“联系作者”可以提交反馈。反馈类型包括：

- 报告 Bug；
- 联系作者；
- 寻求合作；
- 产品建议；
- 账号问题；
- 其他。

请尽量描述出现问题的页面、操作步骤和看到的提示。如果需要说明界面问题，可以附上截图。

不要在反馈中填写密码、API 密钥或其他敏感信息。
