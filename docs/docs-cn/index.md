# EduMirror 使用指南

EduMirror 是一个教育场景模拟与分析平台。你可以选择一个教育或社会行为场景，检查角色和互动设定，运行模拟，并在结果页查看完整过程与分析结果。

## 平台的核心能力

| 核心能力 | 说明 |
| --- | --- |
| 运行模拟 | 让场景中的多个角色按照各自设定完成连续互动，并记录过程日志。 |
| 干预方案对比 | 通过基准条件和干预条件，比较干预前后的互动过程与结果变化。 |
| 需求查看 | 查看角色的核心需求、需求缺口、满意度和行动变化。 |
| 过程与结果分析 | 结合互动日志、过程总结、心理测量和行为评分理解模拟结果。 |
| 历史记录回看 | 重新打开已完成的模拟，查看对应条件、日志和分析结果。 |
| 媒体结果生成 | 根据模拟结果生成场景漫画或视频，辅助展示互动过程。 |

## 推荐阅读顺序

1. [开始使用](quickstart.md)：登录并认识页面结构。

4. [查看结果](results-and-measurements.md)：理解日志、测量和分析结果。

6. [API 设置](api-settings.md)：配置文本、图片和视频生成服务。

## 重要提醒

模拟结果用于辅助理解和比较。请结合互动日志、场景设定和自己的研究目标进行判断，不要只根据自动生成的总结下结论。
