# 开始使用

EduMirror（育镜）是一个用于体验和分析教育场景的在线平台。你可以从平台提供的教育情境开始，了解场景中的角色、互动关系和实验条件，然后运行模拟，观察不同角色在互动过程中的行为与心理状态变化。

平台支持对基准条件和干预条件进行对比，帮助你查看干预方案是否改变了角色的互动过程、核心需求满足情况、满意度和社会价值取向等结果。模拟完成后，还可以查看完整互动记录、角色状态、Surveyor 测量结果和 Rater 行为分析，并根据需要生成场景漫画或演示视频。

EduMirror 中的实验通常围绕具体教育情境展开，例如同伴关系、校园欺凌、家庭沟通或校园活动。下图展示了一个教育场景的示意：不同角色在同一情境中具有不同的行为位置和互动关系，平台会在模拟过程中记录这些角色的行动及其状态变化。

## 登录平台

打开平台网址后，输入邮箱和密码登录。还没有账号时，点击“申请注册”，按页面提示提交申请；审核通过后，根据邮件中的激活提示完成注册。

登录后，页面顶部会显示当前使用的语言、账号状态和剩余运行次数。

登录界面如下图所示：

```{image} _static/screenshots/00-login.png
:alt: EduMirror 登录界面
:width: 40%
:align: center
```

登录时填写已注册的邮箱和密码，然后点击“登录”。如果还没有账号，可以点击“申请注册”提交申请；如果忘记密码，可以通过“忘记密码？”进入密码重置流程。已经在智思体登录的用户，也可以选择“智思体登录”直接进入平台。

## 先认识六个步骤

登录后，平台会按照以下六个步骤组织一次完整的模拟流程：

```{image} _static/screenshots/00-steps.png
:alt: EduMirror 六个操作步骤
:width: 100%
:align: center
```

平台顶部有六个步骤：

1. 选择场景
2. 编辑场景
3. 配置角色
4. 运行模拟
5. 结果分析
6. 媒体生成

通常按照从左到右的顺序操作。已经完成的步骤可以通过顶部步骤条或“返回”按钮重新查看。

### 1. 选择场景

登录后先进入“选择实验场景”页面。你可以通过搜索框查找场景，也可以浏览场景卡片，点击想要使用的场景进入下一步。

下图展示了场景选择页面的主要区域：

```{image} _static/screenshots/01-select-scenario.png
:alt: EduMirror 选择实验场景页面
:width: 100%
:align: center
```

这张图中的几个区域分别用于：

- 顶部步骤栏：查看当前处于“选择场景”的第几步，也可以了解后续操作顺序；
- 搜索框：按场景名称或关键词查找场景；
- 场景卡片：阅读场景简介，点击“点击选择”进入该场景；
- 底部分页：在多页场景列表之间切换。

选择场景时，建议先阅读卡片下方的简短说明，再进入场景查看具体的实验条件和角色设定。

### 2. 编辑场景

进入场景后，可以查看并修改场景背景、参与角色、互动要求和实验条件。编辑场景的作用是确认本次模拟使用的情境内容是否符合你的目标。

编辑场景页面的主要区域如下图所示：

```{image} _static/screenshots/02-edit-scenario.png
:alt: EduMirror 编辑场景页面
:width: 85%
:align: center
```

可以按照下面的顺序理解和操作这个页面：

1. **顶部操作区**：查看当前场景来源，并使用“草稿箱”“恢复默认值”“保存修改”和“确认并继续”等按钮。修改内容后，先点击“保存修改”；确认本页内容无误后，再点击“确认并继续”。
2. **左侧场景列表**：查看当前场景包含的多个场景片段和实验条件。点击不同卡片，可以切换要查看或编辑的内容；基准条件用于查看没有加入干预的原始过程，其他条件用于比较不同设置下的变化。列表中的“自定义干预”入口可以在不改变内置干预分支的前提下，为当前场景添加自己的干预条件。
3. **右侧场景内容**：查看当前选中场景的名称、场景描述和互动要求。互动要求用于说明角色在这一场景中需要如何回应、哪些行为可以发生，以及哪些内容需要保持不变。
4. **角色已知信息**：按角色分别填写进入当前场景时已经知道的信息。不同角色可以拥有不同的信息，这些内容会影响角色后续的判断和回应。

如果页面提供基准条件和干预条件，可以分别查看它们的设置，明确哪些条件代表没有额外干预，哪些条件用于比较干预效果。修改内容后，记得先保存，再进入下一步。

### 3. 配置角色

进入“配置角色”后，页面会按照当前运行范围，把需要参与模拟的子场景分组展示。每个子场景下面列出本场景的角色卡片；同一角色如果出现在多个子场景中，修改一次会同步影响整个实验场景中的共用设定。

```{image} _static/screenshots/03-configure-roles.png
:alt: EduMirror 配置角色页面
:width: 100%
:align: center
```

可以按照下面的顺序理解和操作这个页面：

1. **确认运行范围**：先看顶部提示，确认当前是在配置基准条件，还是在配置某个干预条件。运行范围决定下面会列出哪些子场景和角色。
2. **按场景检查角色**：从上到下查看每个条件卡片中的场景名称、场景描述和角色数量，再阅读下方的角色卡片。不要把不同子场景中的角色设定误认为是同一场对话。
3. **查看角色摘要**：每张角色卡片会显示角色姓名、角色类型、目标和行为特征。先用这些摘要判断角色设定是否符合本场景的互动要求。
4. **编辑具体角色**：需要调整时，点击对应卡片右上角的“编辑”，修改角色目标、行为特征、已有信息、价值取向或核心需求等字段。只修改与研究问题直接相关的内容即可。
5. **保存并继续**：编辑完成后先在编辑界面保存；返回角色列表检查结果无误，再点击顶部的“确认并继续”进入运行模拟。需要放弃修改时，可以使用“恢复默认设置”。

角色设定会影响后续的判断、行动和互动结果。建议先完成基准条件的角色检查，再修改干预条件中的必要角色，这样更容易解释不同条件之间的变化。

### 4. 运行模拟

确认场景和角色后，进入“运行模拟”页面。页面首先要求选择本次运行范围：

```{image} _static/screenshots/04-run-simulation.png
:alt: EduMirror 运行模拟页面
:width: 100%
:align: center
```

1. **基准条件**：只运行不含干预的基础流程，耗时较短，适合第一次检查场景是否正常。
2. **干预条件**：跳过基准条件，只运行各个干预分支，适合集中检查干预效果。
3. **全部实验条件**：先运行基准条件，再依次运行所有干预分支，耗时较长，但便于一次性获得完整对照结果。

选定模式后，查看“当前模式”提示，确认无误再点击“开始运行”。运行期间按钮会变为“停止运行”，页面会持续显示按时间顺序更新的互动日志。完成后，右侧会出现“查看结果”，再进入下一步。

### 5. 结果分析

运行完成后进入“结果分析”页面，先看整体过程，再看角色状态和测量结果：

```{image} _static/screenshots/05-results-analysis.png
:alt: EduMirror 结果分析页面
:width: 100%
:align: center
```

1. **整体过程总结**：阅读基于完整事件日志生成的过程概述，并在需要时回看每一步的原始记录。
2. **角色状态分析**：查看角色需求缺口、社会价值取向（SVO）、满意度和行动次数随全局时间步的变化。
3. **心理测量结果**：展开“大模型调研员”，查看 Surveyor 问卷和结构化测量结果。
4. **行为分析结果**：展开“大模型评分员”，查看 Rater 根据日志识别出的行为证据与评分。

如果页面显示“当前暂无可用的模拟结果”，说明还没有完成可供分析的运行，或结果已经被清理，需要返回运行模拟重新执行。

如果同时运行了基准条件和干预条件，建议先以基准条件为参照，再比较不同条件下的互动过程、角色状态和测量结果，并结合日志确认变化是如何发生的。

### 6. 媒体生成

在结果分析页面点击“媒体生成”，进入媒体生成页面：

```{image} _static/screenshots/06-media-generation.png
:alt: EduMirror 媒体生成页面
:width: 100%
:align: center
```

页面分为两个入口：

- **场景漫画**：点击“生成漫画”，根据当前模拟结果生成场景漫画；
- **视频生成**：先生成视频提示词，再提交视频生成任务。

提交前要确认当前结果对应的是正确的实验条件。漫画或视频生成通常需要等待，页面会显示任务状态；如果还没有完成模拟，媒体入口不会产生可用结果。

## 使用建议

第一次使用时，建议选择一个内置场景，只运行“基准条件”。确认能够看到日志和结果后，再尝试编辑角色或运行干预条件。

- 修改场景或角色后，先点击页面上的保存按钮。
- 想比较干预效果时，先保留一次基准条件结果。
- 模拟运行可能需要一段时间，运行期间不要重复点击“开始运行”。

如需配置模型或媒体生成服务，请参阅 [API 设置](api-settings.md)。
